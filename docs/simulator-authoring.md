# 设备模拟器制作与运行（受限试点）

本流程先制作可运行的设备模拟器。配置练习、评分和任务完成条件是后续独立行为，不属于模拟器制作。AI 仅在制作阶段提出建议；运行中的浏览器不调用模型，也不访问真实设备。

## 制作流程

1. 制作者登录管理端工作台，上传包含根目录 `index.html` 的设备 Web ZIP。原始包保留，不直接改写。
2. 连接获授权的真实设备，限定采集范围，按页面实际顺序采集读、写和前置请求。真实设备每次写操作都需单独批准。保存的证据有顺序、来源、脱敏及截断标记；秘密原值不进入行为规则。
3. 在行为视图审查采集证据、状态和条件分支。AI 可提出推断，但提案不会自动保存；制作者确认后形成新的 v2 修订。模型未配置时可以手工编辑。没有证据的关键读写不能伪装为已采集。
4. 使用隔离预览检查读写、失败响应、刷新和未知接口。登记候选版本并运行声明式浏览器验证；报告绑定包、行为和解释器摘要。仅通过报告并明确确认非阻断推断风险后启用版本。
   可选择冻结的真实设备基线执行受限差分；没有基线时一致性为 `NOT_TESTED`。当前测试阶段工程验证通过后只允许 `DEMO_ENABLED` 制作者演示，不代表真实设备一致性，也不开放匿名或考生启动。
5. 在仿真器站点打开 `/simulators/{versionId}`，使用制作者账号启动已启用版本。每次启动生成独立运行 ID 和 origin；刷新保留这次运行的 IndexedDB 状态，结束后旧页面不能再保存，新启动从初始状态开始。设备登出不等于清空设备配置。

现有 `/runtime` 是独立演示入口，不代表上述版本发布流程。没有真实 AucSeek Web 包时不能声称已适配 AucSeek；仓库样例只验证协议和运行机制。

## 本地试点

管理端通常为 `http://localhost:5174/ai-workbench`，仿真器站点为 `http://localhost:5173/simulators/{versionId}`，Worker 运行域为 `http://{runId}.localhost:3001`。使用 `localhost` 访问仿真器，不能换成 `127.0.0.1`：后端按 Origin 精确校验写请求。浏览器需要支持 Service Worker 和 IndexedDB。运行壳仅在匹配 origin、iframe、运行 ID、协议版本的接管消息到达后显示“运行中”。

启用 AI Compose 覆盖配置时，除了制作者账号、Worker 共享密钥和真实设备目标白名单，还必须设置 `AI_RUN_ORIGIN_TEMPLATE`。生产值须为 `https://{runId}.runs.example.com` 一类独立运行域，不能使用 `*.localhost`，且需配置该域的泛域 DNS、TLS 证书和反向代理至 Worker 3001 端口。仓库提供 `deploy/nginx/conf.d/runs.skilllab.xyz.conf.example` 供部署时按实际域名和证书路径调整；它不是已启用的站点。代理必须保留原始 `Host`，否则 Worker 无法解析对应运行注册；不得把 `/internal` 暴露到公网。仿真器壳的 `SKILLLAB_SIMULATOR_ORIGIN` 和 Worker 的 `AI_RUN_PARENT_ORIGIN` 必须一致。

本仓库当前没有上述生产泛域反代、终端考生身份及公开租户授权配置。该试点只允许已登录的版本制作者运行，不应直接开放给考生或作为生产发布。运行域应与管理端和仿真器壳隔离，真实设备出站访问继续受白名单约束。

## 运行限制

未知接口失败关闭，不转发真实设备；包中外部绝对 URL 需要显式适配。缺失、脱敏或截断的请求字段不能作为确定状态更新依据。运行状态在一次运行内持久化并按事务提交；租约每 30 秒续期，空闲 10 分钟到期，最长 8 小时，结束后立即失效。验证通过不等于任意设备 Web 包都能兼容，仍需针对所需链路采集和回放。
